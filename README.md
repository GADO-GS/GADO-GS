# GADO-GS

Project page for **GADO-GS: Geometry-Appearance Decoupled Optimization for Efficient and Compact 3D Gaussian Splatting**.

Project homepage: <https://gado-gs.github.io/GADO-GS/>

GADO-GS is a structure-first training framework for efficient and compact 3D Gaussian Splatting. It coordinates differentiated geometry--appearance optimization, progressive spherical-harmonic activation, and auxiliary-view geometric consistency within the standard 3DGS training process. The inference-time Gaussian representation and rasterizer remain unchanged.

The project page provides the method overview, qualitative comparisons, and experimental visualizations. The source code will be released through the project homepage upon paper acceptance.
